## 二、第一步：续费（不做这步，后面全都提交不了）

腾讯云规则原文：轻量应用服务器须"包年包月、购买时长 ≥ 3 个月（含续费）、且备案期间剩余有效期 ≥ 30 天"。

当前 11-04 买 1 个月 → 12-04 到期，**剩余 29 天已低于 30 天门槛**，今天提交就会被系统拦截。

操作：

1. 登录腾讯云控制台 → 轻量应用服务器 → 实例 `lhins-ow6yn7yi` → 续费
2. **续 1 年**（到 2027-11-04）。按 2C2G starter 档估值约 ¥70/月、年付有折扣，约 ¥600–800 区间
3. 核对实例详情页「到期时间」已变更

> 为什么不只续 2 个月凑满 3 个月：备案全程 3–6 周，管局审核期不可控；且这台机器是长期生产备选通道，按月续费只会反复踩线。

**续费页面顺带确认**：实例是「包年包月」而非「按量计费」。按量计费不参与备案，如果发现是按量，需要转成包年包月。

## 三、路径选择

### 3.1 三条路的硬对比

| | A. 个体工商户 | B. 个人 | C. 维持现状 |
|---|---|---|---|
| 办照成本 | 线上免费/工本费，1–3 天出照 | 0 | 0 |
| 网站名称 | 可含"社区""互助"，写实际业务 | **不得含"社区/论坛/平台"** | — |
| 服务类别 | 可选论坛/社区类 | 只能选非交互类 | — |
| 域名过户 | **不用**（经营者=刘新建=现域名所有者） | 不用 | — |
| UGC 合规性 | 名正言顺，后续公安备案顺畅 | 高风险，可能事后注销 | — |
| 域名可用 | .cn 立即可用；.com 12-12 后转入备案 | 同左 | 只能 IP 访问 |

### 3.2 推荐 A 的关键理由：不用过户域名

上海管局企业备案明文："域名所有者须为公司中文全称或拼音全称**或法定代表人姓名**"。

个体工商户没有"法定代表人"，只有"经营者"。只要**营业执照经营者填刘新建**，就和 `.cn` 当前注册者「刘新建」完全一致 → 域名核验直接通过，省掉一次过户（过户要 3–5 天，且过户后实名信息要重新入库 3 天，等于多等一周多）。

**办照时务必**：经营者 = 刘新建本人；经营范围写"信息技术服务、互联网信息服务、技术咨询"这类中性表述，**不要写"教育培训""人力资源服务"**（前者触发教育前置审批，后者触发劳务资质）。

### 3.3 如果坚持个人备案

必须接受三条约束，否则驳回：

1. 网站名称改中性（备案名不等于品牌名，用户看到的仍是"育人帮"）
2. 服务类别只能选非交互类，简介不得出现"发帖""评论""注册""互助"
3. 备案通过后**不得立即开放注册功能**——个人备案对应"非经营性静态信息服务"，一旦巡查发现 UGC，会注销备案并可能列入黑名单

> 折中做法：备案期间用"只读模式"（首页/案例广场可看，发帖/评论/注册入口关闭），拿到备案号后先观察 1–2 个月再灰度开放。技术上有现成开关（gate.js 的门槛层），但这是合规灰色地带，风险自负。

- [ ] 通信地址：精确到**门牌号、房间号**（上海管局明确要求，写"XX路"会被退回）
- [ ] 非沪户籍：居住证 + 上海市民服务网（962222.net）居住证状态截图，居住证有效期 > 1 个月，且**居住证地址必须与填写的通信地址一致**

### 5.2 提交路径

1. 腾讯云控制台 → 搜索「ICP 备案」→ 进入备案系统
2. 选择**「首次备案」**（两个域名都从未备过）
3. 备案省份：**上海**（个体户按执照注册地；个人按身份证地址，非沪需居住证）
4. 云资源：选择「轻量应用服务器」→ 选中 `lhins-ow6yn7yi`

7. 提交 → 腾讯云初审 1–2 个工作日

9. 管局终审：上海通常 5–15 个工作日
10. 通过 → 收到备案号（沪ICP备XXXXXXXX号）

**一个坑**：备案期间域名**不要**解析到 `118.89.185.37`。当前 `.cn` 指向 Cloudflare（境外），这个状态是正确的，保持不动。未备案域名解析到境内 IP 会被运营商阻断，还可能影响审核。

## 六、`.com` 的独立时间线

`.com` 走不了同一条线，原因是双重锁定：

| 时间 | 事件 |
|------|------|
| 2026-10-13 | .com 注册（Cloud Yuqu LLC） |
| 2026-12-12 | **60 天注册商转移锁解锁**（ICANN 规则，之前无法转出） |
| 12-12 之后 | 转入腾讯云/阿里云（5–7 天，需续费 1 年 + 转移密码） |
| 转入完成后 | 实名认证 → 等 3 天入库 → 办「新增网站备案」 |

**所以 `.com` 最早 12 月中下旬才能开始备案。本次只备 `.cn`。**

补充判断：`.com` 值不值得折腾？如果 `.cn` 已备案、已能正常访问，`.com` 的唯一价值是防误输入和品牌保护。转注册商 + 再备一次，成本约 2 周 + 一次年费。建议**先办 `.cn`，`.com` 等 12 月有空再说**。

## 七、备案号下来之后的技术动作

按顺序做，每步都可回滚：

### 7.1 nginx 换域名（`deploy-tencent/nginx/yrb-site.conf`）

```nginx
server_name xn--gmqq09al6z.cn www.xn--gmqq09al6z.cn 118.89.185.37;
```

`valid_referers server_names` 依赖这行，同源校验会自动覆盖新域名，无需另改。

### 7.2 上 HTTPS（备案后必做，否则浏览器标"不安全"）

腾讯云控制台申请免费 DV 证书（90 天，可自动续）→ 下发到 `/etc/nginx/ssl/` → nginx 加 443 server 块 → 80 跳 443。

### 7.3 页脚展示备案号（法定义务）

当前 `deploy-cn/index.html` **没有任何备案位**，需要新增，且必须链接到 `https://beian.miit.gov.cn/`：

```html
<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">沪ICP备XXXXXXXX号</a>
```

注意：CSP 已转强制且带 hash 白名单，**新增内联块必须重跑 `temp/sync_deploy.py`** 重新计算 SHA-256，否则页面报 CSP 违规。

### 7.4 公安联网备案（30 日内，UGC 站点必做）

全国互联网安全管理服务平台（beian.mps.gov.cn）→ 注册 → 网站备案 → 提交后约 20 个工作日。通过后页脚再加一个公安备案号。

### 7.5 DNS 切回境内

`.cn` 的 Cloudflare 解析改为 A 记录 `118.89.185.37`。

**这一步要慎重**——意味着放弃 Cloudflare 的 CDN 与 DDoS 防护，回到 2C2G + **4M 带宽**的单机。对图片/视频为主的社区，4M 带宽大约支撑 3–5 人同时看图。

三个缓解选项（届时再定）：

1. 腾讯云 CDN 加速（需备案，按流量计费，约 ¥0.2/GB）
2. 图片/视频继续放 Supabase Storage + 境内 `/sbapi` 代理（现状已是这样，实际静态资源压力不大）
3. 升带宽（4M → 10M，月增约 ¥100）
