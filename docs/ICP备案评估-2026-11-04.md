# ICP 备案可行性评估（2026-11-04）

> 背景：轻量云 `lhins-ow6yn7yi`（118.89.185.37）已部署上线，但只能**用 IP 访问**。
> 境内服务器绑域名必须完成 ICP 备案。这份文档回答"能不能备、怎么备、备不了怎么办"。
> 所有"待核实"项都标明出处不明，不做猜测——备案口径以工信部与各省管局最新公示为准。

## 一、结论先行

**当前身份（个人）走不通。** 育人帮的核心功能是发帖、评论、帮忙回应——属于典型的
UGC（用户生成内容）交互式社区。多地管局对个人备案明确禁止「论坛 / 社区 / BBS /
留言板」类内容，报名时勾选不符或简介里出现"社区""互助""发帖"等词，大概率直接驳回；
即使侥幸通过，后续巡查发现也会被注销备案。

这件事不是"材料准备得够不够"的问题，是**主体资格**问题。所以路线只有三条：

| 路径 | 可行性 | 代价 | 结论 |
|------|--------|------|------|
| A. 企业 / 个体工商户主体备案 | 可行 | 需营业执照；个体工商户办理约 1-2 周，成本低 | **唯一能合法绑域名的路** |
| B. 维持现状：CF 境外托管 + 境内机器只做 IP 访问 | 已实现 | 无法绑域名；境内这台机器对普通访客等于没上线 | 现状，可长期维持 |
| C. 改成纯展示站（去掉发帖/评论） | 技术上可行 | 产品核心没了 | 不考虑 |

**建议**：短期维持 B（现状已跑通，零成本），同时把 A 作为"要不要正式上线"的决策
前置条件。办不办执照，本质是"育人帮要不要成为一个需要承担内容责任的公开站点"。

## 二、为什么个人备案不行（依据）

- 《互联网信息服务管理办法》：个人备案对应「非经营性互联网信息服务」，内容以静态展示为主。
- 论坛/社区类站点的特征是 UGC，监管视其为高风险领域：个人主体不具备内容审核能力与资质，
  一旦站内出现违规信息，负责人承担主要责任。
- 实操层面：多数省份管局审核个人备案时，对含「论坛」「社区」「BBS」「留言板」关键词的
  申请**直接驳回**；北京、上海、广东等严格地区几乎无通过可能。
- 附带义务：交互式站点 ICP 备案通过后**还要做公安联网备案**，并按《互联网跟帖评论
  服务管理规定》落实实名制与先审后发。

> 注：网上确有"某某省个人备案做论坛过了"的说法。那是初审形式审查的漏网，不是合规路径，
> 后续专项核查注销的案例逐年上升。不建议赌。

## 三、若走企业 / 个体工商户备案：需要什么

### 3.1 材料

| 项 | 说明 | 现状 |
|----|------|------|
| 主体证件 | 营业执照（个体工商户即可） | 待办 |
| 负责人证件 | 身份证正反面；非法人办理需授权书 | — |
| 域名 | 注册者须与备案主体一致，且已完成**实名认证** | **待核实**：`育人帮.cn` 现注册者是谁 |
| 服务器 | 腾讯云轻量需能申请「备案服务号」（有购买时长/规格要求） | **待核实**：免费一个月活动机是否满足 |
| 网站名称 | 不能含「中国」「中华」「国家」等；不能与已有备案重名 | 拟「育人帮」 |
| 服务内容 | 须勾选「论坛/社区」或「信息交互」等与实际一致的类别 | — |
| 承诺书 / 核验 | 腾讯云 App 人脸核验 + 电子签 | — |

### 3.2 流程与时间（腾讯云侧）

1. 腾讯云备案控制台提交 → 腾讯云初审（1-2 个工作日）
2. 提交管局 → 管局审核（一般 1-20 个工作日，多数省份 3-7 天）
3. 通过后拿备案号，在网站底部展示并链接工信部
4. 30 日内完成**公安联网备案**（交互式站点必做）
5. 备案信息变更（换主体、换服务器、加域名）需办变更备案

### 3.3 前置审批判断

- **教育类**：纯家长间经验交流、不涉及培训招生/课程售卖，一般不算"教育"前置审批范畴；
  但若站内出现培训机构导流、课程报名，则可能被认定为教育培训服务，需教育部门前置审批。
- **新闻类**：站内不得有时政新闻、社会热点评论板块。
- 结论：保持"家长互助经验交流"定位，避开培训与新闻，可规避前置审批。

## 四、备案通过后才做的事（本仓库视角）

1. `deploy-tencent/nginx/yrb-site.conf` 的 `server_name` 改成真实域名
   （`valid_referers server_names` 会跟着生效，同源校验自动覆盖新域名）
2. 上 HTTPS：certbot（`--nginx` 插件自动改写配置）或直接用腾讯云免费证书
3. 页面底部加备案号 + 工信部链接（属于法定义务，不是可选项）
4. `_worker.js` 里的 CSP / HSTS 在换域名后要重跑 `npm run verify:csp`
5. 公安联网备案号同样需在页面展示
