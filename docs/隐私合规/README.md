## 三句话结论

1. **技术底子够**：同意闸门、限时签名、脱敏、RLS、零广告 SDK 都做到了。
2. **"说了做不到"的三类硬伤已清（2026-10-28）**：虚假状态删掉了、装饰开关撤掉了、政策补齐并如实写。
   剩下的只有**必须等云端**的注销与导出，政策里已如实标注「过渡期经反馈渠道人工处理」，不写"已经可用"。
3. **过审的硬门槛不是代码，是备案与托管**：Cloudflare 境外托管无法作为 ICP 备案接入商。
   按你的决定：先继续 Cloudflare 跑业务，站做起来后再迁境内——但备案号、主体全称、机房区域这三项
   在政策里仍是「待补充」，**没填之前不能对外宣称已合规**。

## 自动化

```bash
npm run privacy:audit     # 完整报告（回归项是门禁，P0 只报告）
node scripts/privacy-audit.mjs --strict   # 整改完成后开严格模式，把 P0 锁死
```

`npm run verify` 已内置回归项检查（10 条）：同意闸门、政策正文、限时签名、脱敏、无障碍语义、常驻入口、
设置页零虚假状态、隐私页零装饰开关、政策必备条款、政策版本号一致。
端到端另有 `tests/core/privacy-test.js`（16 项）：入口可达、零开关、政策关键条款、阅读模式不代勾同意、儿童规则、零虚假状态。

> 改回去就红——这是"整改"与"整改过又忘"的区别。
