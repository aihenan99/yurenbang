# 第三方审核准备清单

> 面向"企业网站要过第三方审核"。按**审核类型**拆，每项写清：要求 → 现状 → 缺口 → 动作。
> 结论先说：**技术可整改，备案与托管是硬门槛**——Cloudflare 境外托管无法作为 ICP 备案接入商。

---

## 一、网站备案（ICP）——最硬的一关

| 项 | 内容 |
|---|---|
| 要求 | 在中国大陆提供互联网信息服务，须以**境内接入服务商**完成 ICP 备案；`.cn` 域名另需实名认证 |
| 现状 | 域名 `xn--gmqq09al6z.cn`；托管 **Cloudflare Pages**（境外接入商，无法备案） |
| 判断 | **过不了**。不是材料问题，是接入位置问题 |
| 解决路径 | ① 迁境内托管（阿里云 OSS+CDN / 腾讯云 COS+CDN / 境内轻量服务器）→ 以该服务商备案；② 或改用已备案主体的境内主机做反向代理（体验会变差，不推荐） |
| 依赖 | 《迁移评估-Cloudflare-D1R2.md》——境内托管与云数据库选型可一并解决 |
| 材料 | 营业执照、法人身份证、域名证书、真实性核验（人脸）、网站负责人信息、承诺书 |

> 备案是**微信内打开、安卓应用市场、小程序、广告投放**的前置条件。没有备案，其它审核基本无从谈起。

## 二、公安联网备案

| 项 | 内容 |
|---|---|
| 要求 | 网站上线 30 日内在"全国互联网安全管理服务平台"备案，页脚展示备案号 |
| 现状 | 未办 |
| 动作 | 拿到 ICP 备案号后 30 日内提交；需网站安全管理制度、应急处置预案（已有：本目录两份文档） |
| 材料 | ICP 备案号、主体信息、负责人、安全管理制度、应急预案、服务器信息 |

## 三、等保 2.0（二级）

| 控制项 | 要求 | 现状 | 缺口 |
|---|---|---|---|
| 身份鉴别 | 双因素、口令复杂度 | 短信验证码 + 后台 bcrypt 密码 | 后台可视为双因素 ✅ |
| 访问控制 | 最小权限、分级授权 | RLS + 管理员白名单 | `is_admin()` 待落地 |
| 安全审计 | 日志 ≥6 个月，防篡改 | 仅云平台日志 | **无自建审计日志** ❌ |
| 入侵防范 | 最小服务、漏洞修补 | 方法白名单、限流、CSP | 无定期漏扫 ❌ |
| 数据备份 | 定期备份 + 恢复演练 | 依赖服务商快照 | **无恢复演练** ❌ |
| 个人信息保护 | 见隐私合规 | 本目录文档 | P0 三项待修 |

**动作**：先做差距自查（本表）→ 补审计日志与备份演练 → 定级备案 → 测评机构测评。
**预估**：自查 1 周；补齐 2–3 周；测评（含整改）1–2 个月。

## 四、渗透测试（第三方报告）

| 项 | 内容 |
|---|---|
| 要求 | 由具备资质的机构出具报告；常见验收线：**高危 0、中危全部修复或有缓解措施** |
| 范围 | 主站、`/yrbapi` 代理、`/yrbtts`、管理后台、存储桶直链、API 越权 |
| 现状 | 已有自测基础：响应头实测、CSP 演练、RLS 自检、举报/注销等业务逻辑审计 |
| 预判风险点 | ① 管理后台仅靠前端白名单（**依赖 RLS 兜底，必须证实**）② 存储桶签名地址可被枚举？③ `/yrbapi` 是否可作开放代理 ④ 限流为单实例级 ⑤ 短信接口可被刷 |
| 动作 | 先自测（可用 `tests/diag` 探针）→ 找机构测 → 按报告整改 → 复测出报告 |

## 五、隐私合规检测（App/小程序专项）

监管通报的高频问题，逐条对照：

| # | 检查项 | 现状 | 结论 |
|---|--------|------|------|
| 1 | 首次运行弹隐私政策，**明确同意**后才收集 | 登录面板内置勾选，未勾选不下发验证码 | ✅ |
| 2 | 隐私政策易访问（≤4 次点击） | 登录面板内 1 次点击 | ✅ 建议再加"我的—关于"常驻入口 |
| 3 | 收集清单与实际一致 | 政策列了 6 类，实际 13 类 | ❌ 用 v2 替换 |
| 4 | 第三方 SDK 清单 | 未列 | ❌ 用 v2 替换 |
| 5 | 注销渠道可用 | **假入口** | ❌ P0 |
| 6 | 权限申请说明（相机/麦克风/位置） | 有文案，无系统级前置说明 | 🟡 补 |
| 7 | 未成年人保护机制 | 仅文案 | ❌ P1 |
| 8 | 定向推送/个性化推荐可关闭 | 假开关 | ❌ P0 |
| 9 | 不得因拒绝非必要权限拒绝提供服务 | 位置非必需，未强制 | ✅ |
| 10 | 数据出境告知 | 未告知 | ❌ P0-5 |

## 六、微信 / 应用市场

| 渠道 | 关键要求 | 现状 |
|------|----------|------|
| 微信内打开 | 域名需备案；不得诱导分享；内容合规 | 备案 ❌ |
| 微信小程序（如做） | 主体资质、类目（社区/教育）、内容安全接口、隐私协议 | 未启动 |
| 安卓应用市场 | 备案号、隐私政策、权限清单、加固、签名 | 目前是 PWA，无安装包 → 走"网页应用"路径更轻 |

> 现实建议：**先以"网页 + PWA"过审**（不涉及应用商店的安装包审核），把备案与隐私合规做实；小程序/APP 作为后续。

## 八、最短路径（按依赖排序）

1. **决定托管去向**（境内 or 继续境外）——这一步不定，后面全是空转
2. 境内托管 + ICP 备案 + 公安备案
3. 修 P0 三项（注销 / 虚假信息 / 假开关）+ 换隐私政策 v2
4. 补审计日志与备份演练（等保自查）
5. 渗透测试 → 整改 → 复测
6. 提交隐私合规检测 / 渠道审核

**预估**：以你目前的工程基础，技术侧 3–4 周可到位；备案与测评的**外部等待**约 1–2 个月。
