# 儿童个人信息处理规则（专门规则）

> 依据：《个人信息保护法》第 31 条、《未成年人网络保护条例》、《儿童个人信息网络保护规定》。
> 适用：不满 14 周岁儿童的个人信息。▲ = 待运营方填写。

## 一、基本立场

1. 本平台**不面向儿童独立提供服务**，仅由监护人（父母或其他监护人）代为操作并全程陪同。
2. 儿童个人信息属**敏感个人信息**，处理前必须取得**监护人单独同意**——不与用户协议、隐私政策打包。
3. 一旦发现未经监护人同意收集了儿童信息，**立即删除**，并记录处置过程。

## 二、哪些内容会被认定为"儿童个人信息"

| 情形 | 举例 | 处理 |
|------|------|------|
| 直接标识 | 姓名 + 学校/班级、身份证号、学籍号 | 发布时提示遮蔽，命中即拦 |
| 间接可识别 | 校服 + 校门 + 班级牌、门牌号、车牌 | 提示遮蔽，人工复核 |
| 图像/音视频 | 正面清晰照、含姓名的奖状、家庭住址背景 | 发布前弹监护人确认 |
| 健康/特殊教育信息 | 诊断、康复记录、残疾评定 | 按敏感信息处理，默认不公开索引 |
| 位置 | 精确到小区/学校 | 仅保存城市级；精确定位一律不存 |

## 三、监护人同意的取得与留痕

1. **触发点**：发布内容被判定涉及儿童时（关键词 + 用户勾选"涉及孩子"）→ 弹出确认层。
2. **确认内容**（原文）：
   > "我确认我是该未成年人的监护人或已获得监护人授权，同意在育人帮发布上述内容；
   > 我已知悉内容将公开可见，并已隐去孩子的姓名、学校、班级、住址等可识别信息。"
3. **留痕字段**（仅存证据，不存额外隐私）：
   `account_id`、`consent_version`、`consented_at`、`content_id`、`ip_hash`（单向哈希，不留原 IP）。
4. **撤回**：监护人可随时在「我的—设置—账号与安全」撤回授权，撤回后相关内容 72 小时内下架。

## 四、儿童信息的特殊保护措施

| 措施 | 现状 | 待办 |
|------|------|------|
| 默认不进搜索引擎 | 案例库为静态页，可能被收录 | 儿童相关页加 `noindex` |
| 不做个性化推荐 | 无推荐算法 | 保持 |
| 不做商业营销 | 无广告 | 保持 |
| 存储期限最短化 | 未区分 | 儿童内容随删除即时清理，不做冷备长期保留 |
| 后台访问最小化 | 管理员可看 | 查看儿童内容记审计日志 |
| 删除响应 72 小时 | 未实现 | 随注销/删除 RPC 一并做 |

## 五、监护人的权利（比一般用户更宽）

1. **查阅**：可要求提供孩子相关全部内容清单（含已删除内容的删除凭证）。
2. **更正/删除**：72 小时内处理；紧急情形（如已造成扩散）**立即下架**。
3. **拒绝**：可拒绝任何涉及孩子的处理，不影响监护人本人使用其它功能。
4. **投诉**：对处理不满，可向网信、教育、公安部门投诉。

## 六、内部管理

- 处理儿童信息的岗位（内容审核、管理员）**单独授权**，离职即撤权。
- 儿童信息**不得导出到本地**、不得用于测试数据；测试一律用合成数据（假姓名/假学校）。
- 年度至少一次专项自查，形成记录（自查表见《第三方审核准备清单》第四部分）。
