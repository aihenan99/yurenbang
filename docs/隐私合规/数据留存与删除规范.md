# 数据留存与删除规范

> 两条硬约束：**留存有上限**（不留"以防万一"的数据）、**删除可验证**（能证明删干净了）。

## 一、留存期限总表

| 数据 | 载体 | 期限 | 到期动作 |
|------|------|------|----------|
| 账号（手机号、用户名映射） | `yb_accounts` / `auth.users` | 账号存续期 | 注销后 15 个工作日删除 |
| 用户档案 | `yb_profiles` | 同上 | 同上 |
| 求助/回应/案例 | `yb_posts` / `yb_comments` / `yb_cases` | 至用户删除或注销 | 删除行 + 删素材 |
| 媒体文件 | 存储桶 | 随内容 | `storage.remove` |
| 玫瑰/答谢记录 | `yb_gifts` | 3 年（纠纷留证） | 匿名化（去 user_id，保留计数） |
| 举报与处置 | `yb_reports` | 3 年 | 匿名化 |
| 错误日志 | `yb_errlog` | **90 天** | 定时清理（`created_at < now()-90d`） |
| 访问日志 | 托管/CDN | ≥6 个月（法定） | 由服务商轮转 |
| 管理密码摘要 | `yb_admin_guard` | 至更换 | 覆盖写 |
| 本地缓存 | 浏览器 | 至用户清除 | 退出登录时清会话 |
| 备份 | 服务商快照 | 30 天 | 自动过期 |

## 二、注销 SOP（15 个工作日，7 天冷静期）

**T+0 用户提交**
1. 二次确认弹窗（写明：将删除的内容、不可恢复、7 天内可撤回）
2. 写入 `yb_delete_requests`（`account_id`、`requested_at`、`status='pending'`、`due_at=+7d`）
3. 立即：退出登录、清本地缓存、隐藏全部内容（`status='hidden'`）——**先停止扩散，再谈删除**

**T+7 冷静期结束**（用户未撤回）
4. 调用 `yb_account_delete()`（SECURITY DEFINER，仅本人或管理员）：
   - `storage.remove` 该用户全部媒体（含缩略图）
   - 删除/匿名化 `yb_posts`、`yb_comments`、`yb_cases`、`yb_profiles`、`yb_gifts`（匿名化保留计数）
   - 删除 `yb_accounts` 行、`yb_delete_requests` 行（改记 `yb_delete_audit`）
   - 删除 `auth.users` 记录（平台鉴权）
5. 写审计凭证：`yb_delete_audit`（`account_hash`=sha256(id+salt)、`deleted_at`、`items_count`、`operator`）
   —— **只留哈希与计数，不留内容与手机号**

**T+15 前回复用户**：已删除的数据类型、媒体数量、保留项及法定理由（如举报留痕已匿名化）。

## 三、删除验证（打勾才算完）

- [ ] 数据库：`select count(*)` 该 `account_id` 在 6 张表均为 0（或仅剩匿名化行 `user_id is null`）
- [ ] 存储桶：按前缀 `userId/` 列举为空
- [ ] 鉴权：`auth.users` 查无此号，且该手机号可重新注册（说明未残留唯一约束）
- [ ] 搜索：站内搜索该昵称无结果；静态案例页已重建（如涉案例）
- [ ] 缓存：CDN 与浏览器强刷后不再出现
- [ ] 凭证：`yb_delete_audit` 有记录，且**不含**原手机号/昵称

## 四、特殊情况

| 情形 | 处理 |
|------|------|
| 涉及未成年人且已扩散 | 立即下架（不等冷静期），72 小时内完成删除并告知监护人 |
| 涉及违法内容被举报 | 内容留存至案件处理完毕，但**限制访问**；仅管理员可查，记审计日志 |
| 法定留存冲突（如司法调取） | 只保留被要求的部分，其余照删；在回复中说明依据 |
| 用户仅要求删除部分内容 | 单条删除，即时生效，无需冷静期 |

## 五、定期任务（挂 automation 或后台手动）

| 频率 | 任务 |
|------|------|
| 每日 | 处理到期的 `yb_delete_requests`（T+7 触发删除） |
| 每周 | 清理 90 天前 `yb_errlog` |
| 每月 | 抽查 3 条删除请求的"删除验证"清单是否全绿 |
| 每季度 | 核对本表与 `db/schema.sql`、`个人信息收集与共享清单` 是否一致 |
