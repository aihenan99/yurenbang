# 个人信息收集与共享清单（对外公示版底稿）

> 用途：① 隐私政策附录；② 应用市场/微信审核提交材料；③ 内部数据资产台账。
> 与代码一一对应，改代码必须同步改本表（`scripts/privacy-audit.mjs` 会检查关键字段）。

## 一、收集清单
